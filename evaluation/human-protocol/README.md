# Human testing protocols (prepared, not yet run)

These materials are ready to use for real human testing. Nothing here has been run yet; any future results go through [../METHODS.md](../METHODS.md) and are labeled as real-participant data, separate from agent reviews and AI-simulated runs.

| File | Purpose | Status |
|---|---|---|
| [usability-protocol.md](usability-protocol.md) | Session script for 4–6 adults rusty at algebra (think-aloud with the tutor, then two problems without AI) | Prepared |
| [consent-text.md](consent-text.md) | Informed consent text to read/collect before a session | Prepared |
| [blind-second-scorer.md](blind-second-scorer.md) | Instructions for a second human scorer of evaluation transcripts (blind pass, agreement reporting) | Prepared |
| [manual-voiceover-check.md](manual-voiceover-check.md) | Step-by-step manual VoiceOver script with expected announcements | Prepared |
| [review-form.md](review-form.md) | Structured form every structured review pass fills in (clarity, accuracy, usefulness, gaps + severity scale); first used by the [agent review](../agent-review.md) | Prepared — in use |

Rules that apply to all of them: adults only (no minors — that would need school/parent approval and a privacy review); informed consent before anything; collect no personal data you don't need; report qualitatively, no causal claims; never describe a usability session, a second scorer, or a VoiceOver pass as done until it has actually happened.
