Live demo — bring your own key

A minimal chat with the tutor, running entirely in your browser against your own OpenAI-compatible API endpoint (that is any AI provider whose chat API uses the same request format as OpenAI's). There is no server behind this page: the key never leaves your browser except in the request to the provider you choose.

Before you paste a key:
  • Use a restricted key with a spending limit. This page has no rate limiting and no cost cap — your key, your quota.
  • The key is kept in memory only (a JavaScript variable). It is never saved to localStorage, cookies, or logs, and closing the tab erases it.
  • The key is sent only to the base URL you enter below, directly from your browser. There is no proxy in between.
  • Your provider must allow direct browser (CORS) calls. Some providers block browser requests or require an opt-in header; if requests fail with a network/CORS error, that is usually why. Check your provider's browser/CORS policy.
  • Do not paste a production or broadly-scoped key. Do not share personal information in the chat.

1. Connect a model

No key connected. The chat is disabled until you connect a key — nothing is sent anywhere until then.

2. Practice

No key? See the example transcripts — the no-key way to see how the tutor behaves (pending real evaluation runs). Connect a key above to start. The tutor uses the v3 draft system prompt from the specification at temperature 0 (a provider setting that keeps replies steady and repeatable — it has nothing to do with how hard the math is), expecting to help with linear equations like 3x + 5 = 20 after you have had a lesson on them.

Two things this tutor will not do: it will not hand over answers before you have genuinely attempted the problem (that is the whole point), and it does not need any personal information — please don't share any.

Enter sends · Shift+Enter adds a new line · Math is plain text (3x + 5 = 20)

What this page does and does not store

  • Stored: nothing. No localStorage, no cookies, no analytics, no server. Reloading the page clears everything, including your key and the conversation.
  • Sent: two things. Your messages and the conversation so far go to the API base URL you entered, with your key in the authorization header. Nothing else, nowhere else.
  • Logged: nothing. The page never writes your key or messages to the browser console.
